# Noxte — فروشگاه بج‌های مینیاتوری

فروشگاه آنلاین برای فروش بج و عروسک‌های ۱–۲ سانتی‌متری چاپ سه‌بعدی به عنوان هدیه همکاران.

## قابلیت‌ها

- **فروشگاه محصولات** — ۱۶ بج مینیاتوری با ویژگی‌های اخلاقی مختلف
- **ناوبری بر اساس شخصیت** — فیلتر بر اساس ۱۲ ویژگی اخلاقی (مهربان، خلاق، رهبر، ...)
- **مشاور AI هدیه** — توصیف همکار یا آپلود اسکرین‌شات چت برای پیشنهاد بج مناسب
- **خرید عمده** — تخفیف تا ۳۰٪ برای خرید بالای ۱۰۰ عدد
- **سبد خرید** — با محاسبه خودکار تخفیف عمده

## اجرا

```bash
npm install
npm run dev
```

سایت روی [http://localhost:3000](http://localhost:3000) اجرا می‌شود.

## پنل ادمین

آدرس: [http://localhost:3000/admin](http://localhost:3000/admin)

- **ورود:** رمز پیش‌فرض `admin123` (قابل تغییر با `ADMIN_PASSWORD`)
- **سفارشات:** مشاهده، فیلتر، تغییر وضعیت، حذف
- **تنظیمات AI:** مدیریت کلید OpenAI و انتخاب مدل

```bash
# در .env.local
ADMIN_PASSWORD=your-secure-password
ADMIN_SECRET=random-secret-string
```

## تنظیم AI

برای استفاده از GPT در مشاور هدیه، کلید را از **پنل ادمین** (`/admin/settings`) یا `.env.local` تنظیم کنید:

```bash
cp .env.local.example .env.local
# OPENAI_API_KEY را در .env.local تنظیم کنید
```

بدون API key، الگوریتم محلی بر اساس کلمات کلیدی فارسی و انگلیسی کار می‌کند.
